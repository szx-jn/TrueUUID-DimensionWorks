# 自动生效的鉴权连接设置

`1.0.9-dimensionworks.2` 将鉴权连接设置放在模组内部，使用单例异步
HttpClient；每次登录请求按相同策略执行，启动脚本和开服面板无需额外
填写 IPv4 或 authlib-injector 排除参数。

## 行为

- 仅鉴权客户端固定使用 TLS 1.2；保留默认信任库与 HTTPS 主机名校验。
- 连接超时 5 秒、单次请求超时 8 秒；连接中断或超时最多重试一次。
- HTTP 204 等无效会话响应不重试，TLS 证书错误不重试。
- 网络异常保留异常原因并传给登录流程，拒绝时显示认证服务连接失败。
- 原客户端协议、认证决策、MSL 白名单与 UUID 注册表格式保留 1.0.9 基线。

该改动对应 Java 17 默认 HTTPS 请求出现 EOF/连接超时、而 TLS 1.2 探针
正常响应的实测故障。Mojang 与所用 MSL 会话服务支持 TLS 1.2；自定义
认证服务也需支持该协议。DNS 错误、网络封锁和认证服务停机需要恢复网络。

## 验证

本地完整构建及 24 项测试通过，其中 6 项为新增 HTTPS 测试。测试使用临时生成的 localhost
证书与本地 TLS 1.2 服务，覆盖读取中断后重试恢复、无效会话不重试、
重复中断保持失败、有界超时，以及拒绝不可信证书和不匹配的主机名。
证书只供测试使用，随临时目录删除，不进入正式 JAR。

另将本地验证 JAR 中的实际传输类放在远端临时目录，用现场 Java
`17.0.20.1` 和同一 authlib-injector 运行探针。未传 IPv4 或包排除参数，
Mojang 与 MSL 会话接口均返回 HTTP 204 / HTTP 2。无效会话编号的 204
只证明 HTTPS 请求成功，不证明真实账号鉴权。

未进行该版本的游戏内登录或迁移验收。
